# 本地操作

打开 http://127.0.0.1:8766。

1. 在“模型连接”检查官方订阅登录；可启用自定义 API。密钥填写环境变量名称。
2. 在书库选择已保存 PDF，或导入新文献。
3. 新建转换：选择页码范围、每批页数、并发、模型及官方订阅思考强度。目录／前置页可显式指定，留空使用前 3 页。
4. 面板左侧显示原页，右侧按需显示本页 TeX；批次进度可跳转到对应页。
5. 暂停会停止新任务派发，正在进行的请求完成后保存。恢复不会丢弃成功批次。
6. 展开“请求与用量”查看最新 50 条请求、用途、耗时、模型和真实 token 汇总。
7. 完成后查看输出 PDF 或下载 TeX 工程。尚未完成时下载的工程包含候选结果，以压缩包中的 `status.json` 为准。

旧运行只读展示，可下载旧产物。新建任务使用 v0.6，不复用旧 MinerU 结果来冒充新版视觉转换。

关闭浏览器不停止后台服务。服务重启后未完成运行显示暂停，需要点击恢复。
