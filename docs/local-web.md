# 本地操作

打开 http://127.0.0.1:8766。

1. 在“模型设置”的连接区域检查 ChatGPT 或 Grok 官方订阅登录；可启用自定义 API 并粘贴密钥。自定义通道用“检查连接”实际访问 `/models` 或一次最小 ping，确认地址与鉴权。Grok 登录使用设备码：打开官方页面，必要时输入设置页显示的授权码。
2. 在书库选择已保存 PDF，或导入新文献。默认紧凑列表，也可切换卡片视图；布局会保留。支持按书名搜索，以及按最近导入、书名、页数排序。每本书可重命名、移入回收站或在资源管理器中定位原 PDF。删除只移入回收站，可恢复，原 PDF 和已有转换任务保留；恢复后可新建转换。运行记录统一从左侧进入。
3. 在“模型设置”分别保存全书设置、转换、衔接、标题、标签与引用、引用局部修复、最终编译和模板迁移的连接、模型及思考强度（low / medium / high / xhigh / max）。公共 TeX 阶段按 global 给出的规则由程序生成，不单独调用模型。新建转换只选择页码范围、每批页数及并发，各阶段模型从设置页复制。目录／前置页可显式指定，留空使用前 3 页。
4. 面板左侧显示原页，右侧按需显示本页 TeX；批次进度可跳转到对应页。
5. 暂停会停止新任务派发，正在进行的请求完成后保存。恢复不会丢弃成功批次。运行页不再放模型表单，只保留“更新模型配置”按钮。先保存设置页，再点击该按钮；下一次请求前读取当时保存的整套阶段配置，已开始的请求继续使用原配置。仅修改设置页不会改变已有任务。重试沿用所属阶段的思考强度，不自动提升到结构强度。超时、限流或临时失败会在后台重试最多 5 次后再暂停，可直接恢复。
6. 展开“请求与用量”按批次查看页码、失败原因、尝试次数和当前结果。重试中、已恢复、重试耗尽分别显示；展开可查看每次请求的错误、模型、耗时与用量。每页 50 组，可翻页；运行中打开面板会自动刷新，用量仍按所有实际请求累计。
7. 完成后查看输出 PDF 或下载 TeX 工程。尚未完成时下载的工程包含候选结果，以压缩包中的 `status.json` 为准。

旧运行只读展示，可下载旧产物。新建任务使用 v0.7，不复用旧 MinerU 结果来冒充新版视觉转换。

关闭浏览器不停止后台服务。服务重启后未完成运行显示暂停，需要点击恢复。


### 书库中的成功结果

所有任务（包括正文转换、图片修复、模板重排）编译成功后，结果只保留在任务中，不自动更新书库。用户预览后点击“保存到书库”，才将工程依赖、生成 PDF 和工程 ZIP 独立保留在 `.bookanalyst/books/<book-id>/results/<result-id>/`，原书保存为同一书籍目录内的 `source.pdf`。保存会新增结果，不覆盖旧副本；已有成功任务也可手动保存。书库卡片和列表的默认 PDF 打开最近保存的生成结果，“原书”单独打开来源 PDF，“TeX”下载已保存的工程，文件夹按钮打开该书籍位置。没有保存结果时，默认 PDF 仍打开原书。局部转换结果标明原书页码范围。

保存失败会保留任务的编译成功状态并显示重试提示。成功报告中的工程／PDF 校验值若与当前文件不一致，需重新编译后才能保留。软删除及恢复书籍会同时保留这些文件。


### TeX 模板管理与重排

左侧“TeX 模板”支持新建、编辑、删除、导入 `.tex` / ZIP 和导出 ZIP。模板保存主文件、应用说明与多文件资源；文本可直接编辑，字体、图片等资源保留原内容。模板大小上限 20 MB、200 个文件，主文件必须是模板内的 `.tex` 文件。

书库有已保留工程的书籍显示“换模板”。选择模板后创建独立重排任务，使用设置页的“模板外观迁移”模型配置；ChatGPT 官方订阅使用 Codex SDK，Grok 官方订阅与自定义 API 使用 Pi。任务复制当前已保留工程及模板快照，跳过转换和引用处理；即使原工程已经编译通过，也先调用 agent 应用模板。仅迁移外观：样式放在 `bookanalyst-template.tex`，依赖放在 `template-style/`；原 `main.tex` 只允许插入样式加载语句，其余原工程文件保持不变（生成的 `main.pdf` 除外）。样式冲突在导入的样式层内有限修正，不改原文档类、正文、定义和编号。修改或删除模板不会影响已创建的任务。可在任务页观察请求、暂停、恢复，或点击更新模型配置应用设置页中的新值。

重排完成并通过编译后，任务页显示“保存到书库”。用户可先查看输出 PDF 或下载 TeX 工程，再手动选择保存；保存前不更新书籍，保存后原结果副本仍保留。失败或暂停不会替换当前书库 PDF。模板文件与正文均为样例／文献数据；只有应用说明用于表达用户的排版要求。
