# 本地 Web 操作流程 v0.1

更新：2026-09-05。首版交互入口已确定为本地 Web 界面。本文定义用户操作、程序响应和界面反馈；执行阶段、成员权限与通过条件沿用 [严格工作流](workflow.md) 和 [执行契约](workflow.contract.json)。首版界面和后端已实现；下文保留目标操作契约，当前实现范围见 [实现状态](implementation.md)。

## 1. 运行方式与职责

用户在浏览器操作本机服务。后端程序管理文件、运行记录、后台任务和服务调用；默认仅监听本机回环地址。MinerU 和 LLM 继续通过各自适配器参与已有工作流。

| 参与者 | 职责 |
| --- | --- |
| 用户 | 选择书籍、处理范围、运行参数；查看证据；必要时提交修正依据或重新执行操作 |
| Web 界面（程序） | 展示后端状态、定位内容、提交操作，不自行判定阶段通过 |
| 后端与执行器（程序） | 校验操作及修订、登记预算、调度 S0–S8、管理来源映射、产物和恢复 |
| MinerU、各 LLM 角色 | 按现有工作流生成解析结果、候选和审查证据，由程序校验后提交 |

运行记录保存在本机。关闭或刷新浏览器不终止仍在后台执行的任务；重新打开时读取已保存状态。后端进程中断后的恢复仍须校验依赖、账本和远端任务状态，不因重新打开页面而重复提交请求。

## 2. 页面与入口

| 页面 | 展示内容 | 主要操作 |
| --- | --- | --- |
| 书籍与运行 | 已登记 PDF、历史运行、处理范围、阶段状态和阻断问题 | 添加 PDF、选择已有书籍、配置并启动运行、打开运行 |
| 内容对照 | 原始 PDF、解析内容、TeX 候选或已通过结果、差异证据 | 按章节或问题定位、查看原图、提交带依据的修正、局部重跑 |
| 结果 | TeX 工程、编译结果、验收报告、真实处理与核对范围 | 查看结果、导出工程与报告 |
| 设置 | 独立的 LLM 供应商连接和 MinerU 服务配置 | 管理连接、登录、选择默认模型、查看能力与连接状态 |

供应商的字段和接入顺序以 [LLM 供应商配置](llm-providers.md) 为准。设置页属于应用基础设施，不作为 S0–S8 中的一个阶段。供应商设置保存连接及默认模型；本次运行如何绑定分析、转换、审查和多模态核对角色，由运行参数负责。

## 3. 从书籍到结果的操作顺序

| 顺序 | 用户操作 | 程序响应与界面反馈 |
| --- | --- | --- |
| 1 | 选择已登记书籍，或添加 PDF | 登记本地文件及哈希，展示书名与物理页数；添加文件本身不提交解析请求 |
| 2 | 选择运行模式与范围 | 展示实际目标页和对应测试限制；默认测试书为已保存的《Elliptic partial differential equations of second order》，选择它不自动开启全书转换 |
| 3 | 设置解析策略、角色模型、并发与预算 | 选择 MinerU 线上或本地连接；设置 LLM 并发、四个角色模型、多模态核对范围及累计预算；连接缺项可跳转设置页 |
| 4 | 启动运行 | 固定本次配置并执行 S0；检查通过后按顺序推进。界面持续展示当前阶段、已完成任务、请求预算和明确的失败原因 |
| 5 | 查看内容或阻断问题 | 打开内容对照页；正常运行自动推进，人工处理仅用于已有阻断或用户主动修正 |
| 6 | 提交修正或发起局部重跑 | 程序依据来源修订和依赖确定失效范围，按原有检查、审查及预算规则重新执行 |
| 7 | 查看并导出结果 | 分别显示完整书籍、样本或离线夹具的验收结果，以及原图核对范围；通过 S8 后提供对应范围的已验收工程 |

主界面默认转换整本书，配置项为 MinerU 策略、LLM 并发和明确填写的累计请求预算。没有按页数选择处理模式的入口。解析结果可复用整本缓存；页序号只用于原文定位和视觉证据选择。有限测试模式仅保留在开发 API 中，用于隔离服务接入问题。

阶段进度按后端实际完成数展示；没有可靠总量时显示状态和已完成数量。解析完成、TeX 生成、编译通过、内容审查和原图核对分别展示，单项成功不能表示整本转换已验收。

## 4. 内容对照与定位

宽屏默认并排三栏，窄屏允许切换栏位，并保持当前选中对象：

| 栏位 | 内容 |
| --- | --- |
| 原始 PDF | 原页图像、选中区域、相邻页上下文与局部放大 |
| 解析内容 | 适合阅读的文本、公式及结构；可展开查看 MinerU 原始 JSON、规范内容和变更记录 |
| TeX | 对应片段的代码、数学表达预览、审查状态及修订；尚未生成时明确显示待生成 |

章节导航以目录锚点及校验后的标题树组织；问题列表按位置、类型和处理状态定位。点击任一栏中的已映射对象，其他栏定位到关联来源或产物。缺少映射时明确显示，不能凭页面位置猜测对应关系。

关联使用来源 ID、原子 ID、任务 ID 和修订记录，不要求三个栏位同步滚动，也不假定原 PDF 与重新编译的 PDF 页码相同。界面将物理页索引转换为从 1 开始的 PDF 页序号用于导航；原书印刷页码仅在有依据时另行标注。两者都不转成最终 TeX 的分页指令。

多模态核对展示实际送入模型的原页或裁剪图像、独立视觉读数、MinerU 读数、差异说明和处理记录。完整页核对与局部区域核对分别计数；未核对、只做抽样和全部核对完成分别显示。模型支持图像不能显示为已经核对内容。

## 5. 问题处理与局部重跑

每个问题至少展示位置、原始证据、当前候选、阻断原因和建议动作。用户提交的是带理由与来源的处理记录；修正建立新修订，程序重新执行相关通过条件，不能用界面按钮直接把阻断项改成通过。

| 问题类型 | 操作与执行路径 |
| --- | --- |
| 需要看清公式或文字 | 从原 PDF 放大、补充上下文；增加模型核对目标时修订核对计划，并沿用累计预算与补充证据次数限制 |
| MinerU 完全遗漏内容 | 定位原页区域，退回 S1 处理对应解析分块，再更新受影响的聚合内容和下游结果 |
| 规范内容识别有误 | 提交原图依据和修改前后内容，在 S2 建立新修订并复核；更新全部受影响的后续依赖 |
| 标题结构或编号规则错误 | 退回 S3 或 S4；全书配置变更后使所有依赖该配置的任务失效 |
| TeX 片段表达有误 | 退回对应 S6 任务，重做检查、独立审查、相邻边界审查、合并和验收 |
| 模板或编译依赖问题 | 定位 S7 错误；修复依赖或模板后执行相应阶段，内容问题仍退回其来源阶段 |

执行前展示程序计算的受影响阶段、任务数量和剩余预算，由用户通过一次明确的重跑操作发起。重跑不清零调用计数和修正次数；需要增加预算时保存新的配置修订。运行中的旧请求与新修订隔离，迟到结果只归档。

从旧页面提交操作时必须带上所查看的修订；修订已变化则提示刷新并查看新证据，不将旧操作应用到新内容。提交按钮等待后端响应期间不可重复派发，后端使用操作标识避免刷新或重复点击导致重复任务。

## 6. 导出与首版验证

正式导出沿用结果清单，包含 TeX 源工程、依赖资源、编译结果及验收报告。用于排错的候选文件可以单独下载，但必须标注未验收状态和对应修订。

验收报告同时写明处理范围与原图核对范围。整本流程通过但只核对部分原图时，界面和导出报告都保留这个区别。

实现后的最小验证覆盖以下操作链：

- 从项目已保存的 532 页测试书打开新建运行，确认整书范围、显式预算与上游动态模型选择；通过开发 API 创建离线夹具验证执行页面，不产生真实书籍提交。
- 选择一处公式，核对原页、解析内容、TeX 之间的定位和修订一致性。
- 展示一条有来源的视觉差异，完成定点修正、必要复核及受影响任务重跑。
- 刷新页面或恢复后台任务时保留进度与累计预算，不重复调用服务。
- 验证供应商设置独立于阶段列表，只有完成验收的当前修订能够显示已验收结果。

当前浏览器回归覆盖整书创建入口、动态模型列表、离线运行、三栏定位、跨页标题跳转、阶段重跑、真实编译、导出与设置保存。真实视觉差异修正、完整自动补充取证和真实 LLM 调用尚未验证，详见 [验证记录](validation.md)。
