# 独立图片修复

左侧“图片修复”标签页用于已保留到书库的转换结果；书库中的“修图片”也可直接进入。

1. 选择书籍，勾选要检查的图片，点击“检查并修复所选图片”。
2. 使用模型设置中独立的“图片修复”连接、模型及思考强度，逐图发送原页、当前裁图和附近 TeX。可选择与正文转换不同的视觉模型，检查和新裁图复核都使用此配置。
3. 模型判断当前裁图是否完整；需要重裁时返回原页归一化坐标，程序从原页重新截取（不是在旧裁图上继续裁），再把原页、当前旧裁图和实际新裁图一起交给模型比较。复核模型选择更好的版本，并独立判断选中的图是否已完整正确；更好但仍有问题的新图也可保留。模型也可独立设置插入宽度，选择新图时一并应用提议的宽度。
4. 待确认的图片自动再次进入修复，携带上次判断与复核原因，以选中的版本继续检查。每张最多尝试 3 次（含首次；每次重裁另有一次新旧图比较请求），确认通过即停止；达到上限仍待确认时，保留选中的版本和具体原因。暂停、继续沿用已完成次数，不重置上限；其他图片继续。界面逐图显示当前尝试次数。
5. 本轮结束后集中编译，工程和 PDF 保留在修图任务中，不自动更新书库。可先预览或下载，确认后点击“保存到书库”，将所选任务结果设为书籍当前版本；旧版文件保留。即使期间产生了其他版本，也可手动选择采用这份结果。

支持暂停、继续及查看原页／修复前／当前裁图。任务出现在运行记录中，打开后回到图片修复标签页。已完成表示本轮处理和编译成功，待确认图片仍单独显示，不表示全书视觉验收通过。

已完成的修图任务支持“全选待确认”、取消全选及逐张勾选，再点击“再次修复所选图片”。新一轮直接复制该任务的当前工程，继承已选优的裁图、插入宽度和其他已修好的图片，无需先保存到书库；原任务和书库版本不变。仅所选待确认图片重新检查，每张重新获得最多 3 次尝试，新任务使用设置页已保存的修图模型及本次并发。新一轮结束后仍需手动“保存到书库”。

普通修复无法解决时，将“修复方式”切换到“特殊修复（Agent）”，勾选目标并点击“特殊修复所选图片”。程序自动发送所选图片的待确认／失败原因、上一轮裁剪与复核记录、原页图像、旧裁图、当前裁图和附近 TeX，不需要填写修复要求。特殊模式也允许选中检查失败或已处理但仍有问题的图片。

特殊修复使用图片修复模型，复用结尾编译员的原生工具、权限和持久会话：订阅连接使用 Codex，自定义 API 使用 Pi。Agent 可读取原书、查看图片、运行命令和图像处理脚本，修改选中图片及相关 TeX、图注、子图结构和局部布局，编译后检查实际 PDF。一个会话处理本次所选目标，暂停后继续同一会话和工程；普通模式的三次裁图尝试不用于计数 Agent 内部工具调用。原书和原任务不变，仍需手动保存结果到书库。Agent 必须给出逐图结论，无法确认的继续标为待确认；程序独立编译验证，编译成功不等于视觉确认。

图片修复有独立的默认并发；创建任务时可用“本次修图并发”覆盖，不修改正文转换或其他任务。未完成的任务点击“更新模型与并发”后，后续请求使用设置页已保存的修图模型及当前输入的并发；已发出的请求不取消，已完成的图片不重查。任务结束后的待确认图片可直接再次修复；想重新检查已确认或已修复的图片，请从书库当前结果新建修图任务。

旧设置初次显示时以原转换配置作为修图配置的初始值，保存后独立维护。已有修图任务保持原冻结配置，直到显式更新。

主流程仍为原来的七步，不增加图片验收阶段。生成工程仅额外保存 `image-assets.json`（图片 ID、原 PDF 页码、裁剪框、文件路径、DPI 和来源 PDF 标识；修图后还记录显式插入宽度 `width_ratio`）。旧书可从原转换批次及模板任务来源恢复记录；没有来源的图片会显示原因，不自动猜测。

检查模型使用 `keep / recrop / uncertain` 三种判断。`bbox` 为整张原页的 `[left, top, right, bottom]`，左上角为原点，范围 0–1；仅 `recrop` 使用。`width_ratio` 为可用正文宽度的比例，范围 `(0,1]`，例如 `0.5` 表示半宽，`null` 保持现有尺寸。`keep` 可同时设置宽度，`recrop` 可同时设置裁剪框和宽度；`uncertain` 不应用本次参数。重裁复核返回 `choice=original/candidate`、`confirmed` 和比较理由；选择旧图时不应用本次重裁及宽度。复核只判断实际裁图内容，不声称已核验排版尺寸，也不增加逐图编译。

普通图片任务在独立工程副本上操作，不改正文和图注。显式宽度只改对应图片的插入命令（标准 `\BAFigure{id}` 或直接 `\includegraphics{assets/id.png}`），生成带宽度参数的 `\includegraphics`，保留图片 ID、来源和其他图片设置。宽度以当地 `\linewidth` 计算，保持长宽比，高度最多为正文高度的 80%；PNG 像素不因插入尺寸改变而重采样。旧版固定正文宽度的标准图片宏仍会更新为只缩不放，缺失的裁图 DPI 按原转换分辨率补齐。自定义模板宏本身不变，明确设置宽度的图片使用新参数。不做版面还原、漏图全书扫描或额外编译代理修复。

接口：`GET /api/books/{id}/images` 查询可修图片；`POST /api/books/{id}/repair-images` 使用当前结果 ID、图片 ID 列表及操作 ID 创建任务；`GET /api/runs/{id}/images` 查询逐图状态；`POST /api/runs/{id}/repair-images` 使用图片 ID 列表及操作 ID，从已完成任务创建新一轮修图（默认普通模式仅允许待确认；mode=special 使用原生 Agent，可选择其他图片）；`POST /api/runs/{id}/retain` 手动保存编译完成的结果到书库。暂停／继续复用原运行操作接口。
