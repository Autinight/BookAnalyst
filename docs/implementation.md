## 程序、MinerU 与 LLM 的实际分工

| 阶段 | 参与成员 | 当前执行 |
| --- | --- | --- |
| S0 | 程序 | 校验 PDF 哈希与物理页范围，冻结预算、解析设置和实际模型 ID |
| S1 | 程序 → MinerU → 程序 | 按页数与实际字节拆分、提交解析、持久化远端任务 ID、解包 JSON／资源并校验页覆盖 |
| S2 | 程序、分析 LLM、多模态 LLM | 列出全部 box type，由分析 LLM 一次给出统一忽略规则，再由程序批量应用；按计划执行图像独立读数和图像／解析比较；语义排序和环境续接由 S3 核对 |
| S3 | 分析 LLM → 审查 LLM → 程序 | 按 block 集群增量分析，携带开放的标题／数学环境及相邻上下文；独立审查每批，聚合后统一匹配目录和跨书引用 |
| S4 | 程序 | 模拟候选计数器，只有唯一符合证据的规则才冻结为全书配置 |
| S5 | 程序 | 优先完整语义子树，较大容器按子节点拆分；公式保持完整，记录唯一归属、只读上下文、环境起止和配置哈希 |
| S6 | 转换 LLM、独立审查 LLM、程序 | 并行生成结构化片段、检查覆盖与数学命令、审查并有限修正，核对相邻任务边界 |
| S7 | 程序、XeLaTeX | 按同一模板确定性合并，真实编译并读取标签核对作者编号 |
| S8 | 程序 | 复查各阶段产物哈希、覆盖和证据，按全书／样本／夹具范围记录结果 |

LLM 提交候选 JSON 与证据，不直接改阶段状态或正式文件。实际状态由 SQLite 中的运行记录与产物 manifest 决定。供应商登录与连接设置属于独立基础设施。

主要代码：`app.py` 提供本地接口，`engine.py` 执行阶段，`pipeline.py` 构造任务，`store.py` 管理账本与修订，`semantics.py` 校验结构与数学表达，`tex.py` 生成并编译，`mineru.py`／`llm.py` 接入外部服务。

## 已实现的恢复行为

- 业务操作带修订和操作 ID，重复操作不会再次派发；过期修订被拒绝。
- 调用在发送前计入预算。请求失败、超时、重启与重跑不会清零用量。
- MinerU 回执在提交前落盘。已有远端 ID 时恢复只查询已有任务；超过原截止时间仍允许先做一次只读核对，若仍在处理则继续受原截止时间与累计轮询上限约束。
- 已取回结果保留 ZIP 哈希；再次恢复使用缓存，哈希异常阻断。远端完成而下载失败单独记录，不解释为解析未执行。
- LLM 请求结果不明时阻止直接重跑，当前尚无完整远端结果登记界面。
- 用户修正先保存修改前后文本与原图依据，从 S2 重新核对才形成下游新产物。S6 可指定片段；其他已通过且输入不变的片段可复用，边界与后续合并重新检查。
- S2 保存并复用一次性类型策略；S3 按输入、模型绑定与 schema 哈希保存每批分析及独立审查；恢复时重放已通过结果，继续尚未完成的批次。
- 图像独立读数和图像／解析比较分别按图像、模型及输入哈希缓存；中途失败保留已返回结果。修改某页解析内容只重新比较该页，原图未变时复用独立读数；每页完成即保存进度。
- S6 使用有界 worker 队列，最多保留指定并发的工作协程；首个失败停止派发新任务，已在途任务完成并落盘。
- S6 片段及相邻边界均可复用，复用前校验内容哈希。转换审查同时读取语义任务、冻结配置和只读相邻 block。指定任务重跑只重新转换该任务、独立审查并重审相邻边界；程序合并、编译和最终验收重新执行。界面可增加累计预算，或显式要求重新计算已通过工作。
- 程序停止后将正在运行的阶段标为待处理，不自动重发外部请求。

## 整书处理边界

S1 的 PDF 页数分块仅满足 MinerU 的接入上限。聚合 JSON 后，S2 按 type 统一过滤，S3 以有界 block 序列分析；S5／S6 以语义子树及其子节点集群转换。跨物理页、跨 MinerU 分块的同一公式可以续接到一个节点，长证明使用同一环境路径。当前解析分块没有重叠页；连续性依赖聚合后的来源顺序、显式续接、独立审查及原图核对，不能据此保证解析器绝不遗漏内容。

原目录保留为标题校验证据，输出使用统一的 `\\tableofcontents` 重建目录。章节、公式与数学环境编号均由冻结配置和统一模板生成，不复制原书分页或坐标。

已用完整 532 页源 PDF 配合明确标记的模拟解析及模型响应执行整书规模回归，覆盖目录、前后引用、公式跨分块、证明跨任务、两次故障恢复和指定任务重跑。真实 532 页 MinerU JSON 已取回，官方订阅联调已开始并据实际响应修正资源路径和审查职责；全书模型保真验收尚未完成，具体结果见 [验证记录](validation.md)。

## 当前限制

| 尚未补齐 | 当前处理 |
| --- | --- |
| 单个超大数学对象 | 不按页或字符截断；提示扩大模型容量或重新解析 |
| 编号候选生成覆盖 | 模型根据有界分层证据提出候选，程序用全部编号验证；无候选或多候选符合时阻断 |
| 大型结构化输出的可靠预算估计 | 以 UTF-8 字节数与固定图像预留保守估算；实际 tokenizer／模型图像计量尚未集成 |
| 完整自动取证策略 | 已对保留正文中的异常控制字符自动选择原图核对页，记录逐项来源；其他疑点仍依赖明确核对计划与模型报告 |
| 复杂表格、任意自定义数学宏、特殊引用格式 | 当前支持固定数学命令集合与常见环境；图表资源可保留为图片，超出支持范围需要处理 |
| 语义级引用重写 | 已有引用目标与编号检查，但尚未把所有原文提及自动重写为语义引用 |
| 人工登记未知 LLM 请求的远端结果 | 记录与阻断已实现，交互入口待实现 |
| 自定义连接完整能力探测 | 用户显式填写模型及图像能力；协议与图像负载经模拟服务验证，真实服务能力尚未探测 |
| 官方运行时内部请求计量与完整取消 | 应用计数一次 turn；运行时内部推理／重试次数未知，不将其视为应用请求次数 |
| 本地模型部署与全书真实验收 | 适配器已实现，尚未在本机部署 MinerU／vLLM 或进行全书推理 |

设计中的所有关卡名称已映射到执行阶段，但关卡完整性只能按已实现检查理解。不得把当前原型宣称为完整设计契约已经全部实现或已完成全书内容保真证明。
