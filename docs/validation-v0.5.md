## 真实运行推动的通用修复

- 在等待模型前保存 thread / turn 标识；恢复读取原请求，不盲目重发。成功批次和哈希一致的候选可复用。
- 指定批次重跑真正传入错误原因并生成新候选；暂停停止后续派发，等待在途结果保存。确认中断且无候选时仅恢复内容修正轮次，保留调用用量。
- 精确编号记录和相同作者 tag 移到元数据不再误判；公共模板统一标题标点，避免重复句点。
- TeX 控制符分词不再把换行后的普通 M、H 误判为宏；原图资源承载图中内容，不要求重复输出 OCR 文字。
- 缺字成为可定位的编译错误；修正来源映射漏计 block 内换行的问题。独立缺字按所属批次并行修复，各模型只收到本批错误。
- S7 每个修复结果立即保存，恢复时校验 S6 输入哈希再复用；公共图片宽度防止无 DPI 资源超出纸面。
