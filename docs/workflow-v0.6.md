# BookAnalyst 工作流 v0.6

更新：2026-09-07。五步执行器已实现；实际验证范围见 [验证记录](validation-v0.6.md)。目标是还原内容，由 TeX 排版。连接配置不属于工作流阶段。

| 顺序 | 参与成员 | 输入 | 动作与输出 |
| --- | --- | --- | --- |
| 1. 全书设置 | 程序、视觉 LLM | 用户指定前置页，默认 PDF 前 3 页 | 提取文档类别、作者编号与标题偏好、可见目录，保存简短设置 |
| 2. 固定公共 TeX 样式 | 程序 | 统一模板 | 提供数学宏包、常用环境、标题与图片接口 |
| 3. 分批视觉转换 | 程序、视觉 LLM | 本批连续页图、简短表达规则 | 并行识别并生成正文 TeX，顺带修正符号；返回页 ID、标题、图片裁剪区及首尾续接状态 |
| 4. 页面衔接 | 程序、视觉 LLM | 前批末页与后批首页的图像及 TeX、继承的环境名称 | 两端均独立闭合则直接拼接；其余边界按原文顺序处理，只应用精确尾部／头部补丁 |
| 5. 标题层级与编译 | 标题 LLM、程序 | 标题清单、可见目录、全书规则 | 模型只修正标题层级；程序应用映射、统一编译，必要时局部修复并导出 |

## 页面与内容边界

程序按 `pages_per_task` 分配连续、不重叠的物理页。例如每批 3 页得到 1–3、4–6、7–9；末批可以不足 3 页。每批建立新会话，没有邻页查询或全书 JSON。

转换模型只收到本批页图与公共表达规则。设置阶段的目录和其他页正文不发送给转换任务。原图是数据，不是指令。不得因推测上下文补写作者没有写出的内容。

保留正文、公式、图表、脚注、参考文献和作者信息；略去重复页眉、印刷页码和装饰。图表可由模型指定本批页内归一化裁剪区域，程序从原图生成资源。物理页 ID 用于来源定位，不强制原书分页。

批内衔接由本批完成。批间可留下半句、跨页公式或未闭合环境，不要求每批独立编译。首尾续接只用简短状态标记，不写疑点登记或逐处纠错报告。

## 官方订阅任务的能力范围

宿主给每次请求建立只含本批 PNG 的材料目录，通过数据 URI 发送图像。关闭 shell、图像文件读取、浏览器、网页检索、MCP、应用、技能和委派能力；使用禁止审批的独立会话。模型不获得原 PDF 或其他批次的内容。自定义 API 直接发送页图，不声明任何模型工具。

运行时还会提供部分内置工具，不能把“配置关闭若干能力”说成所有工具均已消失。较早的最小检查仍报告 `apply_patch` 等内置工具；进一步关闭 code mode 后，专门的编辑能力检查返回 `no_tool`。完整转换的 24 份回执没有工具调用项，实际条目已保存供审计。这些记录不等于操作系统权限证明。

**本机 Windows 原生沙箱的跨目录读取探针没有通过。** 因此当前证明的是宿主发送范围和被关闭的工具能力，不能宣称完成了操作系统级的严格读隔离。只读模式、工作目录和提示词本身也不足以证明。若未来开放放大、裁剪等模型工具，必须由宿主按本批页 ID 校验后执行，不能开放任意路径读写。[官方权限说明](https://learn.chatgpt.com/docs/permissions)

## TeX 与最少结构

程序统一加载 `amsmath`、`amssymb`、`amsthm`、`mathtools`、`graphicx`、`hyperref`。行内使用 `\( \)`，展示公式使用 `equation*` / `align*`，显式保留作者的 `\tag`。定理等公共环境不自动计数，作者编号进入环境标题，避免并行批次计数漂移。

正文标题使用 `\BAHeading{id}`，图片使用 `\BAFigure{id}`。程序为每批 ID 加命名空间。模型不重定义导言区或公共宏。一般数学命令不经过词汇白名单；仅拒绝正文文件操作和执行命令。最终编译从 PATH 找到 XeLaTeX，关闭 shell escape。

接缝模型只看相邻两页和环境栈名称，不回看整段证明。补丁必须匹配原尾部和原头部，不能删除标题／图片锚点。接缝顺序应用，防止重叠修改互相覆盖。

标题模型一次接收提取出的标题列表，页码、ID、作者编号、文字及顺序保持不变，只调整层级。不做逐字目录匹配，不重写全文。尚未自动定位目录书签，也未实现超长标题表的分层拆分；目录页可在创建任务时指定。

## 恢复和停止条件

成功批次、请求回执、接缝结果和编译候选分别即时保存。服务重启后任务显示暂停，由用户恢复；已完成批次复用。已保存的模型响应即使尚未写入阶段检查点，也优先复用。

一次自动转换最多尝试 3 次结构修复；一次最终编译最多 3 轮，后两轮仅针对编译定位页请求修复。失败保存候选和具体错误，手动恢复可以继续新的尝试，不清零历史用量。接缝或标题补丁不合法时停止该阶段，恢复会带上错误重新请求。

结果未知的请求先读取原回执与官方持久会话，不能自动当作失败重发。自定义接口没有通用远端恢复协议时保持未知。

## 成本和完成含义

应用不设输入容量门槛或输出 token 上限。页数控制转换规模，并发受运行与连接两个设置约束。官方订阅可选择思考强度；自定义 API 使用服务默认强度，界面禁用该选项。

45 页、每批 3 页产生 15 个转换任务，通常为 `1 次设置 + 15 次转换 + 实际接缝 + 有标题时 1 次层级处理 + 实际修复`。账本统计应用请求及上游实际返回的输入、输出、缓存和推理 token；推理 token 属于输出，不能重复相加。上游内部推理轮数未知时不推算。

`COMPLETED` 表示页面归属、锚点与补丁检查通过，完整工程成功编译。它不等于已逐行证明内容无遗漏或数学语义完全正确。真实抽查和已知局限单独记录，不增设固定的全篇 LLM 审查。
