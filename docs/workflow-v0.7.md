# BookAnalyst 工作流 v0.7

更新：2026-09-07。还原数学内容，由 TeX 自然排版和计数。保留五步，不增加独立引用映射步骤。供应商连接与鉴权独立配置。

| 1. 全书设置与计数规则 | 程序、视觉 LLM（默认 xhigh） | 指定前置页，默认前 3 页 | 确定文档类别、简短表达规则、可见目录；明确环境共享计数器、复位层级、数字格式 |

## 原书编号直接作为隐藏标签

转换员工看见 Lemma 2.3 时输出：

```tex
\begin{lemma}\label{lemma:2.3}
原书的命题内容。
\end{lemma}

由 Lemma~\ref{lemma:2.3} 可知……
```

`lemma:2.3` 是来源标识，不能设置可见编号。可见的 2.3 由公共导言区中的计数规则自然产生；即使标签名称保持不变，后续编辑导致编号变化，`\ref` 仍取得新的实际编号。公式使用 `\label{equation:2.1}`，引用可用 `\eqref{equation:2.1}`。

统一采用完整小写环境名和原书裸编号：`theorem:2.1`、`lemma:2.3`、`equation:2.1`、`chapter:2`、`section:2.1`、`bibliography:18`。小节仍用 `section`。原生键不加批次或物理页前缀。转换只返回正文、标题、图片、首尾状态，不另写目标登记表或引用登记表。

原书在不同章重复使用 Lemma 1 时，最终结构员工按语义作用域追加后缀，如 `lemma:1:chapter-2`，并修改对应引用。程序按页内命令出现位置定位修改，不能把同一页指向不同对象的引用一起替换。标签原有环境和编号不得因消重而改变。跨批次、前向引用直接使用原生键，交给 TeX 多轮编译解析。

引用其他出版物中的 Theorem 2.3 时保留该外部编号，不连接本书同号定理；本书参考文献条目可以链接，例如 `Theorem 2.3 of [\ref{bibliography:18}]`。参考文献使用固定 `BAReferences` 环境、普通 `\item\label{bibliography:18}`，编号自然递增。

## 全书员工负责计数规则

设置交付 `numbering.rules`：计数器名称、`shared_with`、`reset_by`、数字格式和是否包含父级编号。程序生成普通 `\newtheorem`、计数器复位关系及编号格式。未指定的常见定理环境默认共享 theorem；其他计数器遵循文档类别默认值。

正文不得用 `\tag`、逐对象 `\setcounter` 或手写环境标题编号强行贴号。真正不编号的陈述使用星号环境。编号标题使用正常 `\section` 等命令，标题文字不重复写编号。最后的结构员工指定首个附录标题 ID，程序在该处执行一次原生 `\appendix`，使 A、B 及附录中的公式／引理自然计数。

`numbering.initial` 仅用于节选等需要起始偏移的情况，在文档开头设置一次。编译后程序从 `.aux` 读取每个标签的实际编号，与隐藏的原书编号比较。发生不一致时把紧凑编号清单交回设置员工修正规则；不得靠逐对象强行编号掩盖漏项。此为失败时的定向修复，不增设常驻步骤。

## 内容边界与成本

每批默认 3 页，可调；默认并发 2，同时受连接并发约束。每批新会话仅收到自己拥有的页图与公共规则，不能查询邻页或整书正文。设置阶段目录不发送给转换员工。PDF 内容是数据，不是指令。

保留正文、公式、脚注、参考文献、图表和作者信息；忽略重复页眉、印刷页码与装饰。图片由模型指定本批页内裁剪范围。物理页 ID 用于来源定位，不要求输出保持原分页。

批内续接随转换完成，批间允许保留半句、公式和未闭合环境。接缝员工只收到相邻两页及环境栈名称，不读取完整证明。`BAHeading`、`BAFigure` 是批内接口，由程序加命名空间；原生标签和引用始终保持全局。

程序直接从 TeX 提取标签引用。最终员工收到标签目录；正常唯一引用无需逐条处理，只提供重名和未解析引用的定位与短上下文。无需生成完整引用映射，无需整书再转换一轮。

45 页、每批 3 页：`1 次设置 + 15 次转换 + 需要处理的接缝 + 1 次结构处理 + 发生错误时的定向修复`。不设置输入 token 门槛、输出 token 限额或总调用上限。用量来自实际回执，缓存包含在输入中，推理包含在输出中，不能重复相加。

## 保存、恢复和完成

成功批次与原始回执即时保存。手动恢复复用成功结果；服务重启不会默默重发任务。结果未知时先读取上游原会话，未确认前不重复提交。

转换结构修复和最终编译各最多自动尝试 3 轮；手动恢复允许继续新尝试。结构补丁失败保存具体错误，再次恢复会把错误反馈给原员工。不会清零历史用量。

`COMPLETED` 表示页归属、补丁、标签唯一性、引用可解析性、编译和隐藏编号核对通过，不等于数学内容已逐字证明无遗漏。原文错号、特殊编号形式、节选中指向缺失对象的引用可能仍需处理，不用猜测目标静默通过。

官方运行时关闭 shell、文件读写工具、网页、MCP、技能和委派能力；每次只发送本批图像。**本机 Windows 操作系统级严格读隔离仍未通过独立探针验证**，不能将发送范围或提示词当作完整权限隔离证明。既有证据及限制见 [v0.6 记录](validation-v0.6.md)。
